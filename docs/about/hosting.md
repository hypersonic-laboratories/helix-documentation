# Instant Hosting

**Instant Hosting** is HELIX’s integrated hosting solution that lets creators deploy their worlds to a dedicated server with a single click. No external providers, no manual setup, no maintenance overhead, all running on HELIX’s optimized global network.

---

## Why Instant Hosting Exists

Instant Hosting removes complexities of hosting, so you can focus entirely on building great experiences.

Instead of dealing with:

- Renting, configuring servers from costly third-party providers  
- Installing and updating dedicated server builds (and fixing frequent version mismatches)  
- Configuring ports, firewalls, proxies, and operating systems  
- Maintaining uptime, engine patches, or OS security updates  
- Troubleshooting crashes, latency spikes, or infrastructure failures  

Instant Hosting handles it all automatically for you. And because your world runs directly on HELIX’s optimized network, **you and your players get the following benefits**:

- **Consistent performance & connection** across all servers
- **Lower latency** from optimized routing tailored for HELIX traffic  
- **Reliable uptime** with fast engine and server updates built into the platform  
- **No misconfigurations** or accidental server-breaking mistakes  
- **Safer, more secure hosting** without worrying about exposed ports or compromised machines  
- **Built-in telemetry and debugging tools** that make identifying issues fast and straightforward  

Instant Hosting is much easier to set up and more affordable for creators, and much faster and smoother for players.

---

## How Instant Hosting Works

True to its name, we aim to make Instant Hosting as quick and seamless as possible for creators.
When you deploy a world via Instant Hosting, you receive:

- A **dedicated HELIX server instance**  
- A **dedicated database**  
- Fully managed server updates  
- High uptime backed by HELIX’s infrastructure  
- Network-level protections and consistent performance  

Deployment is one click from Creator Hub or Creator Kit. Once online, it shows up in the server browser for players to connect immediately.

---

## Billing & Renewals (Powered by LIX)

Instant Hosting uses **LIX** for all billing:

- Choose **Daily**, **Weekly**, or **Monthly** renewal cycles  
- LIX is automatically deducted at each interval  

If your balance runs out:

1. You enter a **48-hour grace period**  
2. Your server remains online during this time  
3. If still unpaid after 48 hours, the server is **safely shut down**  

This helps avoid sudden loss of progress while keeping billing fair and predictable.

## Dedicated Database Included

Every Instant Hosting server comes with its own isolated database, automatically provisioned on deployment.

- Fully managed  
- No configuration required  
- Instant access through HELIX APIs  
- Safe from cross-world interference

## Managing Your Instant Hosting Server

You manage your server through **Creator Hub**, with tools designed to make administration simple and safe.

### **Server Controls**
From the Creator Hub dashboard you can:

- **Start / Stop / Restart** your server  
- Edit settings and environment configs  
- Push updates or rebuild after changes  

These actions are safe, atomic, and don’t require any OS-level knowledge.

### **Nucleus Command Center**
You can run real-time console commands through Nucleus, HELIX's integrated console panel.  

- Real-time log streaming  
- Searchable persistent logs
- Kicking or banning players  
- Running administrative commands  
- Debugging scripts  
- Inspecting world or package behavior  

The console is streamed live and updates instantly.
