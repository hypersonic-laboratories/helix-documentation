# 即時伺服器託管 (Instant Hosting)

**即時伺服器託管（Instant Hosting）** 是 HELIX 內置的專屬主機解決方案。它讓創作者只需一鍵，即可將自己設計的世界部署到專用伺服器上。無需聯絡第三方伺服器商、無需繁瑣的手動配置，亦無維護負擔，一切均運行在 HELIX 深度優化的全球網絡上。

---

## 為什麼需要即時伺服器託管？

即時伺服器託管消除了所有維護主機的技術壁壘，讓你得以百分之百專注於打造完美的遊戲體驗。

你再也不需要獨自面對：

- 向昂貴的第三方供應商租用並手動配置主機
- 安裝、更新專用伺服器的構建版本（以及解決頻繁發生的版本不匹配問題）
- 繁瑣地設定連接埠（Ports）、防火牆（Firewalls）、代理伺服器（Proxies）和操作系統
- 定期維護伺服器在線率、修補引擎漏洞或升級作業系統安全補丁
- 排查意外的崩潰（Crashes）、延遲飆升（Latency Spikes）或底層架構故障

即時伺服器託管會為你全自動處理好這一切。而且，由於你的虛擬世界是直接運行在 HELIX 的優化網絡上，**你和你的玩家將會享受到以下好處**：

- 所有伺服器皆能提供**一致的高性能與穩定連線**
- 專為 HELIX 流量量身打造的優化路由，帶來**極低的連線延遲**
- 平台深度整合的快速引擎與主機更新，保障**超高且穩定的在線率**
- **避免人為配置失誤**或不小心改壞伺服器導致的停機風險
- 不需要擔心暴露連接埠或主機被入侵，提供**更安全無虞的託管環境**
- **內置遙測與調試工具**，讓排查與診斷問題變得無比快速與簡單

對創作者而言，即時伺服器託管更易於起步且價格平實；對玩家而言，連線與遊玩體驗則更加流暢迅速。

## 即時伺服器託管如何運作？

正如其名，我們的目標是為創作者提供最快捷、最無縫的部署體驗。
當你透過即時伺服器託管部署你的世界時，你將獲得：

- 一個**專屬的 HELIX 伺服器實例（Instance）**
- 一個**專屬的獨立資料庫**
- 全自動託管的伺服器與引擎更新
- 由 HELIX 全球基礎設施保障的超高在線率
- 網絡層級的 DDoS 安全防護與穩定的吞吐性能

你可以直接在 Creator Hub（創作者中心）或 Creator Kit 中一鍵點擊完成部署。伺服器上線後，會立即出現在玩家的伺服器瀏覽器列表中。

## 計費與自動續費（基於 LIX 支付）

即時伺服器託管完全採用 **LIX** 進行計費與扣款：

- 你可以彈性選擇 **日結（Daily）**、**週結（Weekly）** 或 **月結（Monthly）** 的扣款週期
- 系統將會在每個週期結算時，自動從你的餘額中扣除對應的 LIX

如果你的 LIX 餘額不足：

1. 伺服器將會進入 **48 小時的寬限期（Grace Period）**
2. 在這 48 小時內，你的伺服器將會保持正常在線運行
3. 如果 48 小時後餘額依然未繳清，伺服器才會被**安全且妥善地關閉**

這能有效防止因突然欠費而導致玩家進度丟失，同時讓計費過程更加公平且可預測。

## 內置專用資料庫

每一個透過即時伺服器託管啟用的伺服器，都會自動獲配一個完全隔離的專屬資料庫，該資料庫會在部署時自動創建。

- 全自動管理，無需人工維運
- 免去任何繁瑣配置，開箱即用
- 透過 HELIX APIs 即可在腳本中立即調用
- 與其他虛擬世界徹底隔離，無數據干擾風險

## 管理你的即時伺服器

你可以透過 **Creator Hub（創作者中心）** 來管理你的伺服器，我們提供了非常簡單且安全的管理面板。

### **主機控制台**
在 Creator Hub 的儀表板上，你可以隨時進行：

- **啟動（Start） / 停止（Stop） / 重啟（Restart）** 伺服器
- 修改伺服器選項與環境變數配置
- 發布最新的更新版本，或在變更後重新構建伺服器

這些操作皆具備原子性（Atomic），十分安全，且不需要你具備任何伺服器操作系統的運維知識。

### **Nucleus 控制中心**
你可以透過 Nucleus 運行實時的控制台指令。Nucleus 是 HELIX 內置的網頁控制台面板，提供以下功能：

- 實時的伺服器日誌串流（Log Streaming）
- 可供隨時檢索與搜尋的歷史持久化日誌
- 實時對玩家進行踢出（Kick）或封禁（Ban）
- 執行各類管理指令
- 實時調試 Lua 腳本
- 監控世界或特定套件（Package）的行為與狀態

控制台的所有數據均為實時推送，無延遲更新。

## 未來計劃推出的功能

在後續的版本更新中，我們將為創作者引進更強大、更靈活的主機管理功能。

### **自動定期備份**
你的伺服器和資料庫將會依據設定的排程進行自動備份，並支持自訂的保留策略。

### **狀態快照（Snapshots）**
創作者可以隨時手動拍攝快照，備份當下的：

- 伺服器狀態（Server State）
- 資料庫完整內容
- 配置文件

這在進行版本回滾、沙盒測試或為世界打版本標籤時非常有用。

### **彈性配置與擴展**
提供橫向與縱向的自動彈性擴展選項：

- 升級 CPU 或記憶體（RAM）規格
- 針對高活躍玩家群擴展資料庫性能
- 為大型限時活動啟用彈性負載擴展

### **團隊協作權限控制**
邀請協同開發者或管理員共同管理你的伺服器，支持基於角色的精細權限管理。

### **全方位數據分析與指標**
深入觀測並掌握：

- 實時與歷史在線玩家人數
- 伺服器性能指標（CPU / RAM 使用率）
- 腳本執行效率與負載
- 資料庫數據佔用大小
- 頻寬佔用與流量走勢圖表

所有觀測指標都將直觀地呈現在 Creator Hub 的視覺化圖表中。
