# Vault

**Vault** is the official hub for discovering, downloading, managing, selling, and publishing packages inside the HELIX ecosystem.  
It’s the foundation of how creators share content and how players and server owners bring creations into their worlds safely and consistently.

---

## What Are Packages?

A **Package** is a self-contained bundle of content made for HELIX.  
Packages can include:

- Maps and levels  
- Vehicles  
- Characters and skins  
- Wearables and cosmetics  
- Animations  
- Scripts and logic  
- Props and models  
- Full addons or systems  
- Audio, UI, and more  

Every package includes:

- Files  
- Metadata  
- Version info  
- Preview assets (thumbnails)  
- Dependencies  
- Permissions and settings  

Packages can be installed into worlds, added to builds, or shared publicly through Vault.

---

## Why Vault Exists

In most modding ecosystems, creators rely on scattered third-party sites, Discord links, or ZIP files floating around the internet.  
This leads to:

- Version mismatch issues  
- Broken dependencies  
- Missing files  
- Outdated or unsafe downloads  
- Confusing installation processes  
- Difficulty tracking creators or updates  
- Zero security or provenance  

Vault solves all of these by being a **single, trusted, platform-wide source of truth**.

---

## How Vault Benefits Creators and Players

Vault gives **creators** a clean, unified place to publish and update packages with:

- Automatic dependency tracking  
- Version history  
- Metadata and tagging  
- Ratings and reviews  
- Secure distribution  
- Built-in previews  
- A centralized profile and portfolio  

Vault gives **players and server owners** a simpler, safer experience:

- One-click installs  
- Automatic updates when creators push new versions  
- Visible permissions and dependencies  
- Trust indicators (creator profiles, ratings, reviews)  
- Safer downloads — no random ZIP files from untrusted sources  
- Consistency across all worlds  

By keeping everything inside HELIX’s ecosystem, Vault ensures packages work as intended, remain up to date, and remain safe for everyone.

## Current Vault Features

Vault already includes a robust set of creator and player tools:

### **Reviews & Ratings**
Users can review and rate packages, helping surface quality creations and encouraging accountability.

### **Dependencies**
Packages automatically list any required dependencies.  
If an animation pack requires a rig, Vault ensures the user has it installed — or installs it for them.

### **Versioning**
Creators can publish updates without breaking older content. Users can pin specific versions or opt into auto-updates.

---

## Upcoming Vault Features

### Package Encryption
Creators can choose to encrypt their packages (scripts, assets) when uploading to Vault. When encrypted, source files are never shown to end users, including to customers who have purchased the encrypted package. However, hackers or malicious actors may attempt to crack such encryption using various methods so this should be considered a deterrent rather than an absolutely bulletproof system.

### Paid Packages
Creators can sell packages as one-time purchases through Vault. Once purchased, users gain permanent access to the package and all updates included under that purchase, unless otherwise specified by the creator.

### Paid Subscriptions
Creators can offer subscription-based packages with recurring access to a selection of packages in addition to one-time purchases of individual packages. 
Subscriptions allow creators to continuously ship improvements, fixes, and new features across several packages while earning predictable recurring revenue. Access automatically expires if a subscription lapses.

### Seller Profiles
Every creator can set up a public seller profile that showcases their creations, products, services, and stats such as average product review and response time. This helps buyers evaluate trust, quality, and long-term support before purchasing or subscribing. Over time, seller profiles become a form of reputation capital, rewarding creators who consistently ship high-quality, well-supported content.
