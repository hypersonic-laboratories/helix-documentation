# Basic Controls

These are the essential controls for navigating and building in HELIX.

---

## General Gameplay Controls

- **`1–5`** – Inventory slots
- **`X` (Hold)** – Voice chat
- **`T`** – Text chat
- **`B`** – Emote
- **`K`** – Respawn
- **`Z`** – Toggle between **first-person** and **third-person** view
- **`Scroll Wheel`** – Adjust camera zoom distance
- **`F6`** – Photo Mode
- `/` – Hide Keybinds
- `.` – Fly Mode
- `ESC` – Pause Menu

## Build Mode

Build Mode allows you to place and edit assets in your world. *(Note: Build Mode is disabled in multiplayer.)*

![image.png](https://r2.fivemanage.com/ElKst3CCVvlhlgHiaH5IM/basiccontrols_1.png)

### Entering Build Mode

- Press **N** to toggle Build Mode.

> 📖 Learn more in the [Build Mode tutorial](https://development.helix-documentation.pages.dev/tutorials/buildmode).
> 

### Camera & Navigation

- **Right Mouse + WASDQE** – Free-fly movement (forward/back, strafe, ascend/descend)
- **Select actor in Outliner + Z** – Focus/center the camera on the selected actor

### Asset Placement

- **Shift + Drag from Library** – Place assets with **physics disabled** (prevents vehicles from exploding during placement)
- **Drag Player Start** (`CREATE → Player Start`) – Spawns a new player start location
    - Use the **Teleport** button in its Properties Panel to instantly move your character there

---

👉 With these controls, you can smoothly navigate, position assets, and set up your world in HELIX.
