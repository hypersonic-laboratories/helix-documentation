# 平台簡介

歡迎來到 [HELIX](https://helixgame.com/){.external} 的官方開發者文檔！HELIX 是專為多人聯機沙盒與角色扮演（RP）設計的次世代遊戲創作平台。

![橫幅圖片](../_images/getting_started/banner.png)

## 關於 HELIX

HELIX 是一款多人聯機沙盒平台，旨在提供最極致的自由度。作為開發者，你可以利用我們豐富的腳本 API 和強大的創作工具，開發屬於你自己的遊戲、角色扮演伺服器以及虛擬世界。

<div class="annotate" markdown>

- :fontawesome-solid-people-line: **創作者至上**{.whiter} - 我們從零開始打造 HELIX，使其無論在開發還是遊玩上都同樣輕鬆簡單。你可以全面釋放腳本 API 的威力、利用龐大的套件庫與編輯器工具導入任何類型的自訂素材，隨心所欲地打造多人聯機體驗。

- :material-chart-areaspline: **完整的智慧財產權（IP）所有權**{.whiter} - 在其他遊戲上開發模組時，創作者總是面臨被版權方隨時下架的風險。但在 HELIX 上，你對於自己所創作並發布的所有原創作品，都擁有 100% 完整的智慧財產權。

- :material-arrow-up-box: **社群共同開發**{.whiter} - 我們與社群攜手並進，共同打造 HELIX。我們深感重視你的反饋，並直接將社群提出的需求融入產品的每次更新中。如果你對遊戲玩法或開發體驗有任何建議，歡迎隨時加入我們的 Discord 與我們交流！
</div>
