# HelixJS

JavaScript API for HELIX. Create powerful game modes, mechanics and mods with the power of HELIX + JS and its massive NPM ecosystem.

This section has the API reference and tutorials to get you started.

/// warning
The HelixJS API is under active development. HELIX is currently in Closed Alpha, and the JavaScript scripting surface may change between updates. You may encounter bugs or breaking changes; we recommend staying on top of release notes and updating your scripts as the platform evolves.
///
