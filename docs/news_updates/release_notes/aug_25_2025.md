# August 25 2025

### Build \#19719721

### **🚀 New Features**

- **Build Mode**
    - Grid snapping (enabled by default) + new useful tools
    - Pivot points for objects are now on bottom surface and not in center
    - Removed unused tabs on bottom, it’s now cleaner UI
    - Hotkeys now show in BM UI
    - When focusing on an actor in the scene, the Scene Outliner scrolls to the actor in the list
    - Copy/paste support
    - Transform gizmo now works on Levels
    - ~~Right click context menu (paste, “Play From Here”) (EDIT: Coming next build)~~

### **🐞 Bug Fixes**

- WebUI can now load local files in the workspace. You must use absolute path (documentation is still outdated and will be updated soon).
- WebUI is disabled when entering Build Mode. Previously the z-index caused nothing to be clickable and required application restart.
