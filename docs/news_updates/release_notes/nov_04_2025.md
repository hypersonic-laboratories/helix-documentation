# November 04, 2025

### Build \#20251104.9473.435

## 🤘🏻Internal Nightly Branch!

We are opening access to our internal build branch on Steam (`Nightly`). This branch is updated daily with the latest features but not fully QA’d (expect bugs).

1. In your Steam Library, right click on HELIX → Properties → Betas
2. Use this beta access code: `HelixNightly2025`
3. Select the `Nightly` branch and then Play HELIX

You can always switch back to our stable build, however, please note that we have retired the `Pre-Alpha` branch and to switch back you now need to select “None” in the Betas tab instead.
