# September 5, 2025

### Build \#20250902.6802.12

## **🚀 New Features**

### **🔫 Weapons & Inventory**

- New weapon + ammo icons for a cleaner loadout experience
- Quick slots and weapon widgets now display the correct icons
- Press **G** to drop weapons and free up inventory space

---

### **🎥 Camera Improvements**

- Characters in vehicles now turn their heads with view rotation
- First-person vehicle camera now feels more realistic + less janky
- Fixed major blending issue that caused instability and FPS drops
- Smoother first-person camera transitions during animations
- Better vehicle camera collision — no more clipping into nearby cars

---

### **🚗 Vehicle Fixes & Polish**

- Serenity’s right-side doors/windows now use correct meshes
- Hands now follow the wheel properly with improved IK system
- Adjusted seating + steering positions for better first-person driving
- Speedometer now hides automatically in first-person view

---

### **💻 Lua/API Fixes**

- Fixed Trigger callback param order
- Fixed Interactable.Callbacks table error
- Added type safety to InputAction in Interactable constructor
- Fixed chat auto-hide bug
- Fixed cloud coverage for weather system
- Fixed issues with Events system

**📝  Note:** Next build will allow **parameters to be passed from server to client via Lua events** — a major upgrade for scripted systems.

---

### **🧰 Other Fixes & Additions**

- Fixed multiplayer replication issues with hinge doors
- 🧙‍♂️ **New X-Ray Mode:** Shows player profiles while **V** key is held
