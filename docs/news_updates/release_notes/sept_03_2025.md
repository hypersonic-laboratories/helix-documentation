# September 3, 2025

### Build \#20250903.6921.4

## **🚀 New/ Improved Features**

**💻 WebUI**

- Completely overhauled the WebUI class with accelerated paint and updated the related documentation. Now renders 2-3x faster than before. New method for broadcasting to Lua from JS.

**🔧 Lua Events**

- Servers can now pass parameters to clients via Lua events — a major upgrade for scripted systems.

**🎮 Gameplay/UI Fixes**

- Sign Up Screen – Fixed an issue where pressing ENTER attempted to log in instead of signing up.
- Death / “TOASTED” Screen – Removed “Submission by [name]” text to avoid confusion.
- X-Ray Mode Improvements (Hold V and hover over other players to see their profile)
• Now outlines all actors in range.
• Increased detection radius for better visibility.
• When releasing V while looking at another player, a full profile is displayed.

### **🐞 Bug Fixes**

- See above.
