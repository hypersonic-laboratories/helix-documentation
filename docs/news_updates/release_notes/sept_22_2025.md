# September 22, 2025

### Build \#20250922.7609.72

### **🚀  New/Improved Features**

🎮**Gameplay & Menus**

- Server Browser & Pause Menu improvements for better navigation and reliability.
- Improved loading screen behavior (ESC support, fewer glitches).
- Improved handling and dialogues for when joining/leaving workspaces (fewer errors).
- Better Vault & Draft management with smoother updates.

---

🎨**Visuals**

- Fixed several cosmetic and animation bugs (including animation syncing).
- More consistent look for characters and cosmetics when loading.

---

🛠️**General Improvements**

- Upgraded backend and infrastructure (more stable server connections, smoother downloads).
- Removed unused/obsolete systems, reducing clutter and improving performance.
- Logging cleaned up for a more stable client experience.

---

💻**Lua changes**

- Added a parameter to WebUI that allows scripters to determine whether the UI should consume input or not (see docs site for updates documentation).
- Added support for local events i.e. client -> client, server -> server.
- Updated StaticMesh API to fix a collision issue.
- Cleaned up spamming logs for Lua.
- Updated Database API to prevent unintended UE garbage collection.

---

### **🐞 Bug Fixes**

- **Build Mode:** fixed scenarios with lost dependency; pack visibility issues when adding dependencies on top of world launched from “Preview” button in Vault; “DOWNLOADED” filter improvements.
- **Worlds:** fixed player getting stuck when attempting to cancel world creation/connection or UI getting confused thinking player is inside the world.
- **Vault:** fixed “Delete Package” dialogues; searching with special characters not working; player getting stuck when cancelling connection to a world.
- **Menus/UI:** fixed duplicated entries for the same listen server; interaction prompts being too small; Epic Games sign in page spamming.
- **Animation:** fixed player being able to run while pointing; character being able to do emotes while inside a vehicle.
- **Listen Servers:** fixed client seeing placeholder workspace name instead of server name in SERVERS menu and while connected to the server.
