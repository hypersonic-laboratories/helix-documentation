- Game Settings menu UI reskin

🛠️**General Improvements**

- Quit Game option improved when leaving workspace.
- Cleaner handling of shipping PAKs in editor.
- Removed obsolete/invalid references and unused assets.
- Improved security for Web requests.
- More layers & better re-parenting for WebUI.
