# 建立你的第一個 HELIX 世界

*這是一份在 HELIX 上開發與發布伺服器的完整實戰指南。我們將為你解說最核心的基礎概念，包括工作空間（Workspaces）、套件（Packages）、世界（Worlds）、創作者套件（Creator Kit）、藍圖系統（Blueprints）、建造模式（Build Mode）等等。*

## **1. 核心概念介紹**

- **套件 (Package)**：一個模組化的資源包（包含 Lua 腳本、藍圖、UI 介面、網格體、貼圖等）。多個不同的套件可以結合在一起（透過宣告依賴關係），共同組成一個可遊玩的 **世界 (World)**。這非常類似於 FiveM 中的 **資源 (Resource)**。
- **世界 (World)**：是一種**特殊類型的套件**，它包含遊戲的核心邏輯（Lua 腳本、藍圖）以及一個**套件依賴清單**，用以共同拼裝成一個可在 HELIX 中編輯與遊玩的完整體驗。這非常類似於 FiveM 中的 **配方 (Recipe)**。
- **伺服器 (Server)**：是一個**世界的執行實例（Instance）**，可供多個玩家連線進入遊玩。與 FiveM 截然不同的是，HELIX 的伺服器本身並不包含任何遊戲邏輯或美術資源 — 相反，所有的邏輯都完整封裝在「世界」中。你可以點擊[此處](dedicated_server.md)深入了解這個革命性的設計以及如何託管專用伺服器。
    - **本地 (Listen/P2P) 伺服器**
        - 基於點對點（P2P）技術託管。
        - 完全免費，但不具備持久化（當主機玩家離開或遊戲崩潰時，伺服器便會終止）。
    - **專用伺服器 (Dedicated Servers)**
        - 運行在專用的雲端或實體主機上，玩家透過 IP 地址進行連線。
        - 支持高在線人數與數據持久化。
- **資源庫 (Vault)**：是 HELIX 平台官方的**套件管理器（Package Manager）**。套件（包括世界）會上傳至 Vault 進行版本化控制與發布，並由客戶端在本地下載與更新。這非常類似於 NodeJS 中的 **npm** 或 Python 中的 **pip**。
- **創作者工具套件 (Creator Kit)**：是 HELIX 官方發布的 Unreal Engine（虛擬引擎）專用插件，用以將你自訂的美術與代碼資源打包導入至 HELIX 世界中。你可以點擊[此處](creatorkit.md)下載並開始使用。

**核心差異對照表：**

| 功能特性 | 套件 (Package) | 世界 (World) | 伺服器 (Server) |
| --- | --- | --- | --- |
| **主要定位** | 模組化積木（美術與代碼素材） | 整合好的完整遊戲體驗 | 供玩家連線的世界實例 |
| **可否直接遊玩** | 否 | 是（透過伺服器載體） | 是 |
| **可否直接編輯** | 否 | 是（在工作空間內編輯） | 否（需更新對應的世界） |
| **發布途徑** | 發布為 Vault 套件 | 發布為 Vault 世界套件 | 發布為可加入的伺服器實例 |
| **依賴關係** | 支援 | 支援 | 不支援 |

**一個「世界」包含：**

- **套件依賴清單**，包含一個**預設的地圖套件**以及**導入的自訂資產套件**（貼圖、網格體等）
- **Lua 腳本** — 用以定義遊戲的邏輯
- （可選）一個可直接在建造模式（Build Mode）中進行編輯的**動態地圖**

## **2. 建立你的第一個世界與伺服器**

### **建立新世界**

**工作空間（Workspace）** 是一個**本地資料夾**，用以儲存你正在編輯的世界的所有源文件。在整個開發過程中，你將主要在此資料夾中修改程式碼與配置。你可以非常方便地將此資料夾連接到 Git 等版本控制系統中。

1. 在遊戲客戶端中，點擊 **Worlds** 標籤頁底下的 **Create World** 按鈕，並選擇你要使用的地圖。
    ![地圖選擇畫面](https://r2.fivemanage.com/ElKst3CCVvlhlgHiaH5IM/firstworld_4.png)
2. 按下鍵盤 **N** 鍵進入建造模式（Build Mode），在頂部工具列中點擊 **Code（代碼）按鈕**，這會自動為你開啟**本地工作空間資料夾**。
3. 點擊 **Save（儲存）按鈕**，將變更安全地保存在本地。

### **編寫遊戲邏輯**

你可以在你的工作空間（Workspace）中使用 Lua 腳本或藍圖來編寫遊戲邏輯。請跟隨 [這篇指引](../scripting/packageguide.md) 來快速熟悉 HELIX 的 Lua 腳本開發；如果你希望基於 QBCore RP 模板開發角色扮演伺服器，可以前往 [QBCore 安裝指引](../qbcore/installation/) 開始學習。藍圖腳本開發的專屬指南將會於近期發布。

### **配置套件依賴關係**

你可以為你的世界添加來自 Vault 的各種套件（包含像 [QBCore](../qbcore/) 這樣的核心框架）以擴展世界的玩法。點擊遊戲底部導覽列的 **Vault 按鈕**，即可瀏覽並添加所需的套件。你可以在遊戲內的 **Downloads（下載）** 界面中查看下載進度。

請注意：**任何你從 Vault 中添加的套件都是唯讀的，你無法直接修改它們的原始文件。** 你只能修改你自己工作空間（Workspace）內的文件。但你完全可以在自己的腳本中，調用與引用這些依賴套件中的類別、函數與美術資源，並與它們進行數據傳遞。

### **透過 Creator Kit 導入自訂資產**

你可以透過閱讀 [自訂資產導入指南](creatorkit.md#-create-a-new-package)，學習如何將你自訂的任何 Unreal Engine 資源（藍圖、類別、UI、網格體、貼圖、材質等）導入並在你的世界中使用。

### **發布你的世界**

你可以將你的世界發布為**公開（Public）**或**私有（Private）**。一旦發布成功，擁有訪問權限的玩家將能在遊戲客戶端的 **Worlds 標籤頁** 中看見並加入你的世界，該世界也會同步展示在官方網站的 [helixgame.com/worlds](https://helixgame.com/worlds) 上。

---

> [!WARNING]
> **重要注意事項！**
> 如果你的世界中包含了在上一步中自訂導入的本地資產，**你必須先將這些本地套件發布至 Vault，並在世界的依賴清單中完成添加**，然後才可發布你的世界。你可以參考 [Creator Hub 使用指南](creatorhub.md) 了解如何將套件上傳發布至 Vault。

---

在建造模式（Build Mode）中，點擊 **Publish（發布）按鈕**（火箭圖示）即可將你工作空間的最新變更壓縮並全自動上傳發布至 Vault，此時你可以選擇將世界設為公開或私有。

如果設為私有，你可以登入 **[創作者中心 (Creator Hub)](https://hub.helixgame.com/)** > Manage Worlds > Grant Access 來手動為特定玩家開通連線訪問權限。

### **管理草稿世界**

你可以在客戶端的 Worlds 標籤頁中，篩選 **Drafts（草稿）** 標籤，來檢視並繼續編輯你保存在本地的草稿世界。

### **託管專用伺服器**

你可以跟隨 [這篇專用伺服器指引](dedicated_server.md) 來為你的世界搭建 Dedicated Server。這篇指引近期將會更新，以涵蓋更先進的 **HELIX 即時伺服器託管 (Instant Hosting)** 的部署與管理。

### **更新你的世界與伺服器**

如果你想更新你的世界，只需在建造模式中再次點擊 **Publish 按鈕**，並選擇「發布為新版本（Publish as new version）」或「覆蓋現有版本（Replace existing version）」。這會將你的最新工作空間同步至 Vault。之後，請務必重新啟動你的專用伺服器以加載最新的版本。如果你採用的是 HELIX 即時伺服器託管（Instant Hosting），伺服器將會在更新上傳後自動為你重啟並加載新版。
