# Custom Vehicles

You can create three different types of vehicles in HELIX: Basic, Standard, Advanced.

  - Basic: Single body mesh + wheels.
  - Standard: Working doors, glass, seats, steering wheel, lights.
  - Advanced: Detachable, replaceable body parts, panels, color customization, advanced deformation, etc.

This guide shows you how to import a standard custom vehicle with multiple moving parts such as doors, seats, steering wheel, lights, etc. You'll learn how to prep meshes, set pivots, import into Unreal, assemble your vehicle Blueprint, and wire up doors, glass, seats, steering, tires (with deflation), and lights - then finally test the vehicle inside HELIX.
