# Default Materials Guide

HELIX includes a set of **Default Materials** optimized for **performance**, **visual quality**, and **consistency** across all worlds.  

When importing assets, it’s strongly recommended to **replace or reassign their materials** with **HELIX Default Materials**. These materials are already tuned for **lighting**, **shading**, and **texture streaming** in the HELIX engine — resulting in **faster loading**, **smaller file sizes**, and **smoother performance**.  

Using them also ensures your world looks **consistent** with other HELIX creations and avoids packaging **duplicate shaders** or **heavy textures** inside your build.
